This is a fictional example included to show how a case study can be structured.

## The challenge

Every Monday, two people copied numbers from four tools into a spreadsheet, then emailed a PDF. Errors crept in and the report was often late.

## What we did

- Pulled data from each tool via its API on a schedule.
- Calculated the metrics in one place, with tests for the formulas.
- Generated the report and posted it to the team chat and email.
- Added alerts so any failed run is visible immediately.

## Outcome

The report is on time every week, the numbers are consistent, and the team spends the saved hours on analysis rather than copy and paste.
